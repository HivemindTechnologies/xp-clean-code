# Word List

Three lists: inflated words with their plain replacements (R7), vocabulary that marks text as
machine-written (R8, R21), and pairs of words that are often confused. None is a ban list. A
word is fine when it is the most exact one available.

## Commonly Confused

| Pair | Use |
|---|---|
| affect / effect | *affect* is usually the verb; *effect* is usually the noun ("to effect a change" means to bring it about) |
| comprise / compose | the whole *comprises* the parts; the parts *compose* the whole; avoid "comprised of" |
| fewer / less | *fewer* for things you count, *less* for quantities |
| e.g. / i.e. | *e.g.* gives examples; *i.e.* restates exactly |
| imply / infer | the writer *implies*; the reader *infers* |
| its / it's | *its* is possessive; *it's* is a contraction, so write *it is* (H3) |
| principal / principle | *principal* means main; a *principle* is a rule |
| complement / compliment | *complement* completes; *compliment* praises |
| ensure / insure | *ensure* means make certain; *insure* is about insurance |
| dependent / dependant | *dependent* is the adjective; a *dependant* is a person (British) |
| alternate / alternative | *alternate* means every other; an *alternative* is another option |
| practice / practise | British: *practice* is the noun, *practise* the verb |
| licence / license | British: *licence* is the noun, *license* the verb |
| that / which | *that* for restrictive clauses with no comma; *which* after a comma for non-restrictive ones. British usage also allows restrictive *which*, so choose one and keep to it |
| data | plural or mass noun; choose one per document and keep to it (R20) |
| may / might | *might* for the less likely or the hypothetical |
| enormity | means great wickedness, not great size |
| literally | only when the statement is not figurative |
